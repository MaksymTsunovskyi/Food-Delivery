# Аналітичне сховище для сервісу доставки їжі (Modern Data Stack)

**Лабораторна робота №1**
У цьому репозиторії налаштовано локальну інфраструктуру сховища даних:
1. Піднято PostgreSQL за допомогою Docker (`docker-compose.yml`).
2. Написано Python-скрипт (`data_generator.py`) для генерації транзакційних даних (Клієнти, Ресторани, Кур'єри, Замовлення, Маршрути доставки).
3. Налаштовано автоматичне завантаження згенерованих даних у `raw` схему бази даних (Extract & Load).
